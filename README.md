## 📥 Download

Get the newest build from the **[Releases page](../../releases/latest)**. Every release has one AnyKernel3 zip per root manager, plus a plain **Vanilla** zip with no root.

Pick **one** zip. The manager app you install must match the root you flashed. The release page lists the version and commit of each root.

> [!WARNING]
> Back up your boot image before flashing, and report what breaks.

## ✨ Features

- SUSFS
- NoMount
- NTSync
- Choice of five root managers, or none
